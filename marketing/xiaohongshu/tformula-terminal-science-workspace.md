# 在 Agent 时代，终端也变成了最好的学习平台

以前我一直觉得，终端只是写代码和运行命令的地方，真正学习时还是要回到浏览器、PDF 阅读器或者笔记软件。但有了 Agent 之后，我越来越喜欢直接在终端里学习。现在我的屏幕通常分成两边：一边用 TFormula 阅读教材，另一边打开 Agent。TFormula 不只是在终端中显示 LaTeX 公式的工具，本身也是一个完整的 Markdown 阅读器：标题、段落、列表、引用、表格、链接和图片都能以适合阅读的形式呈现；遇到数学、化学公式也会正常渲染，不会露出满屏源码。终端里的 Markdown 因而真正变成了一本可以持续修改的电子教材。遇到不理解的定义或推导时，我只需把问题交给旁边的 Agent，让它解释某一步为何成立、检查单位，或者换一种方式重新推导。

我最喜欢这种方式的地方，是阅读、提问和整理始终发生在同一个环境里。比如学习麦克斯韦方程组时，我会先在 TFormula 中像读教材一样阅读章节，再让 Agent 解释洛伦兹力，追问磁场为什么不做功、叉乘代表什么；真正理解以后，再把关键内容补充到 Markdown 中。文件保存后，TFormula 会实时刷新，新增的文字和公式马上以阅读模式呈现。Agent 的回答因此不会随着聊天记录被遗忘，而会逐渐沉淀成一份自己的教材。不过我不会让 Agent 替我总结一切：每学完一节，我仍然会关掉回答，自己复述概念、重做推导。对我来说，Agent 负责答疑和陪我探索，TFormula 既负责舒适地阅读整篇 Markdown，也负责呈现复杂公式，把零散对话变成结构化、可反复阅读的知识。终端因此不再只是生产工具，也成了一个安静、专注，并会随着学习不断成长的个人课堂。
